# Imágenes del bot (galería MineLoon)

Coloca aquí las capturas del bot (`.png`, `.jpg`, `.webp`).

Luego abre `script.js` y añade los nombres en la constante `GALLERY_IMAGES`, por ejemplo:

```js
const GALLERY_IMAGES = ['bot-1.png', 'bot-2.png', 'bot-3.png', 'bot-4.png'];
```

La galería mostrará automáticamente las imágenes con efecto hover, zoom y lightbox.
Mientras la lista esté vacía se muestran placeholders elegantes.
