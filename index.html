Discord Minecraft Web

Desarrollador de Discord, Minecraft y Web

Soy Arnau, desarrollador especializado en Discord, Minecraft y desarrollo web. Me apasiona crear herramientas, bots y sistemas para comunidades grandes que necesitan soluciones fiables y bien construidas.

Tengo una rutina estable, intento mejorar cada día y siempre estoy aprendiendo nuevas tecnologías para ofrecer proyectos de mayor calidad. Trabajo con seriedad, cuido los detalles y me tomo cada proyecto como si fuera propio.

Enfoque profesional

Código limpio, mantenible y pensado para networks de gran escala.

Constancia

Rutina estable y desarrollo continuo, mejorando un poco cada día.

Mejora continua

Siempre aprendiendo nuevas tecnologías para elevar la calidad.

Compromiso

Comunicación clara y entregas serias con cada comunidad.
